# 작업 문서

`work/docs/`는 버전별 번역 작업의 검수·진행 기록을 보관합니다.

## 공유 문서

`review/`에는 배치별 검수 결과, 번역 진행 상황, 릴리스 검토 기록을
저장합니다. 이 문서들은 Git에 포함되며 다른 작업자가 확인할 수 있어야
합니다.

## 로컬 분석

`analysis/`에는 압축 해제 결과, 인덱스, round-trip 결과, 임시 백업 등
재생성 가능한 분석 산출물을 저장합니다. 파일 크기가 크거나 버전별로
달라질 수 있으므로 Git에는 포함하지 않습니다.

안정적으로 유지할 프로젝트 설계·사용법·절차 문서는 루트 `docs/`에
저장합니다. 실제 번역 파일은 각 버전의
`work/Wargroove <게임>/<버전>/` 아래에서 작업합니다.
