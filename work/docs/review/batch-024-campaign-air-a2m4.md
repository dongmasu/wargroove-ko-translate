## Deferred Findings

### `Fallow` terminology

The A2M4 lines continue to use the established Korean term `불모기`.
Japanese `喪失時代` and Simplified Chinese `沉寂期` suggest a named
historical era. This remains deferred for a campaign-wide glossary decision;
no isolated A2M4 edit is proposed.

## Internal/Developer Text

The opening contains a developer description of an intended scene:

`At the beginning here, we'd show the dead kill a villager and take over the structures they start out with.`

It is already marked and translated as internal text. It requires no
player-facing wording change.
