# Translation Batch 003: Campaign Air Naturalness

Date: 2026-09-26

Scope: Wargroove 2 campaign air, A1M1 opening cutscene.

The existing NSW Korean translation was used as the base. Only strings with a
clear meaning or naturalness issue supported by the English and Japanese
references were changed.

| Key | English / Japanese evidence | Previous Korean | Revised Korean |
| --- | --- | --- | --- |
| `...intro_dialog_023_text` | `Hey Mercia!` / `マーシア、久しぶり！` | 안녕, 머시아! | 머시아, 오랜만이야! |
| `...intro_dialog_055_text` | `private affair` / `私的な事情` | 비공식 자리라는 것만 압니다. | 사적인 일이라는 것만 압니다. |
| `...intro_dialog_085_text` | `Do not!` in the fear-denial context / `怖くないよ！` | 뭐?! 안 그래! | 뭐?! 안 무섭거든! |
| `...intro_dialog_134_text` | `BEST sleepover` / `最高のお泊まり会` | 역사상 최고의 외박이 될 거야! | 역사상 최고의 파자마 파티가 될 거야! |
| `...a2m1...talk_to_vesper...012_002` | `Mon dieu...` / `モンデュー…（やれやれ…）` | Mon dieu... | 아이고... |
| `...a3m1...intro_dialog_008_text` | `C'est impossible!` / `不可能よ！` | C'est impossible! | 말도 안 돼! |

Markup such as `[shaking]` and `[wavy]` was preserved. The revised strings
are included in `work/Wargroove 2/1.2.x/config/strings/` and the Windows
direct-replacement pack.
